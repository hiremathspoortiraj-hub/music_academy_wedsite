SPOORTI RAJ ACADEMY - STATIC WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in your browser.
4. Use the navigation menu to visit Home, About, Courses, Gallery and Contact.

FILES
- index.html, about.html, courses.html, gallery.html, contact.html
- css/style.css
- js/main.js

NOTES
- This is a static front-end mini project (HTML, CSS and a little JavaScript).
- Photos are loaded from Unsplash over the internet, so an internet connection is required to display them.
- The contact form is a front-end demo. It does not send messages until connected to a backend or form service.
- Replace the sample email, address and opening hours on contact.html with the academy's real details before submission.
